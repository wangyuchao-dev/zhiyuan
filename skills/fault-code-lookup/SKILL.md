# 错误码查因

## 什么时候用

用户给出形如 `E1017`、`E2043` 的错误码，或贴出带错误码的报错文本时。

## 步骤

1. **先定位码表**：在《智云平台故障排查手册》中检索「`<码>`」；检索不到就回答「码表中没有该错误码」，不要推测。
2. **给出三要素**：含义 / 常见原因 / 处置动作。三者缺一不算答完。
3. **区分环境**：若用户没说环境，先按「测试环境」给处置，并追问一句「是生产还是测试」。
4. **不要做的事**：
   - 不要凭码段规律猜（`E1xxx` 不一定都是调度问题）；
   - 不要把「联系运维」当唯一答案，除非手册里明确这么写。

## 输出格式

```
<错误码>：<含义>
常见原因：<1~2 条>
处置：<1~3 步>
出处：《智云平台故障排查手册》- <章节>
```

## 边界

- 码表未收录 → 直接说「未收录」，并建议提供完整报错文本
- 同一错误码在不同版本含义可能变化 → 提示用户确认版本
