# samples · 样例语料

这个目录放**仓库自带的测试语料**，用于冒烟测试、演示和复现问题。
全部由我们生成，不含任何真实客户信息。

## 和 uploads/ 的区别（别混）

| 目录 | 放什么 | 是否提交 | 为什么 |
|---|---|---|---|
| `samples/` | 我们造的、无敏感信息的样例 PDF | ✅ 入库 | 别人 clone 下来就能跑冒烟测试、复现问题 |
| `uploads/` | 用户上传的文档 | ❌ 被 `.gitignore` 排除 | 可能含内部资料，体积也不可控 |
| `eval/datasets/` | 评测集（jsonl：题目 + 断言） | ✅ 入库 | 评测要可复现，但语料本身放在 `samples/` |

一句话：**`samples/` 是仓库的一部分，`uploads/` 是这台机器上的运行时数据。**

## 怎么用

**手动试**
启动服务 → 打开 http://127.0.0.1:8000 → 上传 `01` → 问「受限级文档的审计日志要保留多久」。

**冒烟测试**（遍历本目录所有 PDF 走一遍建库流程）
```powershell
.venv\Scripts\python.exe -m pytest tests/test_ingestion.py -v
```
需要 `DASHSCOPE_API_KEY`，会真实调用 embedding，产生少量费用。

**验证清洗与拒收**（不产生费用：被质量门槛拦下的文档不会去调 embedding）
```powershell
.venv\Scripts\python.exe -m pytest tests/test_wiring.py::TestCleanPages -v
```

**重新生成 04–06**
```powershell
.venv\Scripts\python.exe scripts\make_samples.py
```
依赖 Windows 自带的微软雅黑（`C:\Windows\Fonts\msyh.ttc`）；其它系统改脚本里的 `FONT` 即可。

## 加新样例

1. 自己做一份（Word / LaTeX 导出 PDF），放到本目录，编号接着往后排；或
2. 改 `scripts/make_samples.py` 生成 —— 好处是可复现、页数与内容都能调；然后
3. 在上面那张表里补一行：**用来验证什么、预期结果是什么**。
   没有「预期结果」的样例等于没有样例——下次没人知道它是不是还正常。

## 不要放的东西

- 真实客户文档、含个人信息或密钥的文件
- 超过 5 MB 的扫描件（仓库会变慢，需要大文件就用 Git LFS）
- 需要特定字体才能打开的 PDF（别人机器上可能渲染成方块）
